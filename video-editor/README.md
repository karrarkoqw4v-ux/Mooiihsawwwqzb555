# كليبو — محرر فيديو وتطبيق متكامل (video-editor)

محرر فيديو يعمل بالكامل داخل المتصفح (Canvas + WebAudio + MediaRecorder + IndexedDB) دون خادم وسيط.

## التشغيل
```bash
cd video-editor
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```
> المحرر الأساسي يعمل أيضاً بفتح `index.html` مباشرة، لكن أدوات الذكاء الاصطناعي تحتاج الخادم (تحميل wasm ونماذج).
> استخدم Chrome أو Edge. الخطوط العربية تُحمَّل من Google Fonts (تحتاج إنترنت، وإلا يُستخدم Tahoma).

## البنية
- `index.html` / `style.css` — الواجهة (المكتبة يميناً، الخصائص يساراً، المعاينة، الخط الزمني).
- `app.js` — المحرك: الخط الزمني، الرسم، الصوت، الإطارات المفتاحية، الانتقالات، التصدير، حفظ المشاريع.
- `ai.js` — أدوات الذكاء الاصطناعي.
- `vendor/` — مكتبات ونماذج مضمَّنة: MediaPipe Tasks Vision (+نماذج tflite)، Transformers.js (+ONNX Runtime wasm).

## أدوات الذكاء الاصطناعي
| الأداة | التقنية | تحتاج إنترنت؟ |
|---|---|---|
| إزالة الخلفية | MediaPipe Selfie Segmenter | لا |
| التعرف على العناصر / الوجوه | MediaPipe EfficientDet-Lite0 / BlazeFace | لا |
| تتبع الحركة | Template Matching (SAD) | لا |
| قص الصمت | تحليل الموجة الصوتية | لا |
| فيديو من نص | شرائح مولَّدة (+ TTS اختياري) | لا (إلا مع التعليق الصوتي) |
| الترجمة التلقائية | Whisper عبر Transformers.js | نعم، لتنزيل النموذج أول مرة |
| النص إلى صوت | MMS-TTS عبر Transformers.js | نعم، لتنزيل النموذج أول مرة |
| تكبير الصور ×2 | Swin2SR عبر Transformers.js | نعم، لتنزيل النموذج أول مرة |

## الملفات الجديدة
- `shell.js` / `shell2.js` / `shell3.js` — البداية، الحسابات، الرئيسية، القوالب، المشاريع، الإعدادات، الملف الشخصي، تخطيط الهاتف.
- `templates.js` — بيانات القوالب ومحرك المعاينة والبناء.
- `NAVIGATION.md` — خريطة التنقل والتمييز بين المستند رسمياً والإضافات المستقلة.
